# YingYang

> 이슈 #9의 80문항 개편을 운영에 반영합니다. 기존 50문항은 문항 1.0으로 보존합니다. 구현·호환성·검증 한계는 [개편 검증 문서](docs/issue-9-questionnaires.md)를 확인하세요.

**나의 체질을 알아보는 두 가지 검진 웹서비스**

YingYang은 **후천적 체질 검진**과 **타고난 체질 검진**을 제공하는 웹서비스입니다. 질문에 답하고 검진별 결과를 확인할 수 있으며, 관리자에게는 승인된 계정에 한해 기록 조회 기능이 제공됩니다.

- **서비스:** https://yingyangcheck.web.app
- **관리자 페이지:** https://yingyangcheck.web.app/admin
- **새 기본 주소:** https://koreanmbti.com (HTTPS 인증서 발급 대기)
- **새 관리자 주소:** https://koreanmbti.com/admin
- **도메인 전환:** [연결 상태](docs/custom-domain.md) · [Google 심사 보완 설정·회신 초안](docs/google-oauth-domain-update.md)
- **버전:** v1.3.0 (운영 전환 검증 중)

## 관리자 이용 안내 요약

1. [관리자 페이지](https://yingyangcheck.web.app/admin)에서 **Google로 로그인**을 선택합니다.
2. 사전에 승인된 Google 계정으로 로그인합니다.
3. **일반 관리자**는 발송 이력 조회와 생성 후 7일 이내 PDF 다운로드를 이용합니다.
4. **마스터 관리자**는 일반 관리자 기능에 더해 관리자 계정 추가 및 권한 회수를 처리합니다.

> **마스터 관리자 계정의 도움이 필요한 경우 웹마스터를 호출해 주세요.** 마스터 전용 권한은 다른 계정에 별도로 양도하거나 부여할 수 없으며, 해당 업무는 웹마스터가 직접 처리합니다.

## 검진 서비스 기본 기능

- 선천적 사상체질: 40문항
- 후천적 사상페르소나: 40문항
- 필수 응답, 이전 문항 수정 및 진행 상황 표시
- 같은 브라우저에서 응답 자동 저장 및 이어하기
- 검진별 결과 확인 및 완료 후 재검진
- 모바일·PC 화면 지원

## 현재 운영 안내

운영 이메일 전송과 Drive 백업은 서버 설정을 따릅니다. #9 운영 전환 점검에서 기존 Gmail 인증과 Drive 활성 상태를 확인했습니다. 실제 이메일 수신 여부는 발송 접수와 별도로 확인합니다.

검진 응답의 브라우저 자동 저장과 관리자 PDF 보관 기간은 서로 다른 기능입니다. 관리자 PDF 다운로드 가능 기간은 생성 후 **7일**입니다.
