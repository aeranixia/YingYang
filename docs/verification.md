# YingYang v1 검증 기록

검증일: 2026-10-14 (Asia/Seoul)

## 결과

- `npm test`: 테스트 파일 2개, 테스트 21개 통과.
- `npm run build`: TypeScript 검사와 Vite 프로덕션 빌드 성공. 배포 산출물은 `dist/`.
- Windows에 설치된 Chrome을 Playwright로 제어하여 320·390·768·1440px 너비에서 검증. 모바일 너비는 터치·모바일 에뮬레이션이며 실제 휴대전화 검증은 아님.
- 각 너비에서 후천적 10문항·타고난 40문항을 모두 진행. 홈, 전 문항, 개별 결과, 읽기 전용 응답, 확인창, 종합 결과의 가로 넘침 없음. 표시된 버튼 높이는 최소 44px 이상.
- 미응답 진행 차단, 라디오 선택, 완료 결과, 새로고침 완료 유지, 검진별 재검진 독립성 통과. 페이지 실행 오류 없음.
- 대표 홈·검진·종합 결과·확인창·타고난 검진 화면의 스크린샷을 시각 검수. 긴 선택지는 세로 카드 안에서 줄바꿈되며 결과 표와 주요 버튼은 화면 안에 표시됨.
- `vite preview`로 빌드 결과를 제공하여 모바일 너비에서 자산 로딩, 입력, 새로고침 이어하기, 종합 결과 합계 10회 / 80점 확인. HTTP 4xx·5xx와 페이지 실행 오류 없음.

브라우저 검증 도구는 `npm install --no-save --package-lock=false playwright`로 임시 설치하여 실행했습니다. 앱의 `package.json`과 잠금 파일에는 추가하지 않았습니다.

## 발견 및 수정

재검진 확인창의 React `autoFocus`가 효과 실행 전에 포커스를 옮겨 복귀 대상이 취소 버튼으로 기록되는 오류를 발견했습니다. 중복 `autoFocus`를 제거하고 기존 효과에서 초기 포커스를 설정하게 했습니다. 취소 또는 Escape 후 재검진 버튼으로 포커스가 돌아오는 것을 자동 테스트와 네 화면 크기의 실제 브라우저에서 확인했습니다.

원본의 후천적 제목 강조 누락과 네 선택지·문항의 강조 범위를 수정했습니다. 원문 문자, 분류, 집계 및 기존 응답 데이터는 유지했습니다. [원본 대조 기록](source-review.md)을 참고하세요.

## 배포 준비

`dist/`를 정적 호스팅에 게시할 수 있는 상태입니다. 서버·환경변수·데이터베이스는 필요하지 않습니다. 배포 플랫폼은 연결하지 않았고 실제 배포도 수행하지 않았습니다. 체질 판정 알고리즘은 추가하지 않았습니다.

실제 iOS/Android 기기, Safari 및 다른 브라우저의 검증은 수행하지 않았습니다. 흐릿한 인접 글자의 정확한 원본 굵기는 고해상도 스캔에서 최종 확인할 여지가 있습니다.
