## 제품별 삭제 시점

[Firebase 공식 안내](https://firebase.google.com/support/privacy): 인증 IP는 수 주, 그 밖의 인증정보는 고객의 계정 삭제 요청 전까지 유지하고 요청 후 서비스/백업 제거에 최대180일이 걸릴 수 있다. Hosting IP는 수개월이라는 제공자 기준이며 임의로90일로 바꾸지 않는다. App Check는 증명 제공자의 약관과 별도이며 토큰 TTL과 저장기간을 혼동하지 않는다. 현재 설정 TTL은1시간이고 replay protection용30일 보관을 현재 사용 중이라고 단정하지 않는다.

[Gmail 삭제 안내](https://support.google.com/mail/answer/7401?hl=ko)의30일은 휴지통 구간이며 보낸함 보존기간이 아니다. [Google 보관 설명](https://policies.google.com/technologies/retention)은 삭제 처리와 백업에 추가 시간이 걸릴 수 있음을 설명한다. 일반 Gmail에 Workspace/Vault 관리기능이 있다고 가정하지 않는다.

[네이버 공식 메일 안내](https://help.naver.com/service/30029/contents/21317?lang=ko&osType=COMMONOS)의 설정은 실제 계정 설정과 대조해야 한다. 보낸함 관련 설명을 한의원 받은편지함의 자동 삭제 설정으로 적용하지 않는다. POP/IMAP·전달·다운로드·기기 백업은 메일함 삭제와 별도로 확인한다.

[의료법 시행규칙 제15조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0015&lsiSeq=286963&urlMode=lsScJoRltInfoR)의 기록별 기간과 [개인정보 보호법 제21조](https://www.law.go.kr/LSW/lsSideInfoP.do?docCls=jo&joBrNo=00&joNo=0021&lsiSeq=283839&urlMode=lsScJoRltInfoR)의 목적 달성 후 파기·법정 보존 예외를 구분한다. 실제 PDF 원본 분류는 의료기관 책임이다.

## 수동 파기 증빙

직원은 대상 범위·목적 달성/법정보존 판단·처리일·담당 역할·휴지통/동기화 정리 결과를 기존 내부 관리 방식에 최소한으로 기록한다. 환자 PDF·이름·전화번호·계정 자격증명을 공개 이슈에 올리지 않는다. 새 DB·자동 스케줄러는 만들지 않는다. 삭제 책임의 지정과 실제 삭제 실행 완료는 서로 다르다.
