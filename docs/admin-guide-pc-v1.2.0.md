# YingYang 관리자 시스템 이용 안내 (PC용)

> 적용 버전: v1.2.0  
> 관리자 페이지: https://yingyangcheck.web.app/admin

이 문서는 YingYang 관리자 시스템의 마스터 관리자와 일반 관리자를 위한 공개용 이용 안내입니다.

## 1. 접속 및 로그인

1. [관리자 페이지](https://yingyangcheck.web.app/admin)에 접속합니다.
2. **Google로 로그인** 버튼을 선택합니다.
3. 사전에 승인된 Google 계정을 선택합니다.
4. 인증 완료 후 관리자 화면을 이용합니다.

별도의 관리자 ID·비밀번호는 사용하지 않습니다. 계정 역할에 따라 메뉴가 달라집니다.

## 2. 일반 관리자

일반 관리자는 **발송 이력** 메뉴를 이용합니다.

### 발송 이력 조회
1. **발송 이력** 메뉴를 엽니다.
2. 날짜 및 처리 상태 필터를 이용해 기록을 찾습니다.
3. 기록의 처리 시각, 상태, 마스킹된 이용자 정보를 확인합니다.

개인정보 보호를 위해 이름과 전화번호 일부가 가려져 표시됩니다.

### 검진 결과 PDF 다운로드
1. **발송 이력**에서 대상 기록을 찾습니다.
2. 다운로드 가능 여부를 확인합니다.
3. **다운로드** 버튼을 선택합니다.

PDF는 **생성 후 7일간** 다운로드할 수 있습니다. 보관 기간이 지나면 다운로드할 수 없습니다.

일반 관리자는 관리자 계정 목록, 계정 추가 및 권한 회수 기능에 접근할 수 없습니다.

## 3. 마스터 관리자

마스터 관리자는 **발송 이력** 및 **관리자 계정** 메뉴를 이용합니다. 일반 관리자 기능도 사용할 수 있습니다.

### 일반 관리자 추가
1. **관리자 계정** 메뉴를 엽니다.
2. 추가할 관리자의 Gmail 주소를 입력합니다.
3. **관리자 추가** 버튼을 선택합니다.
4. 필요할 경우 Google 계정으로 본인 인증을 진행합니다.
5. 관리자 목록에서 승인 상태를 확인합니다.

### 일반 관리자 권한 회수
1. **관리자 계정** 메뉴에서 대상 계정을 찾습니다.
2. **권한 회수**를 선택합니다.
3. 필요할 경우 Google 본인 인증을 진행합니다.
4. 목록에서 계정 상태를 확인합니다.

**마스터 관리자 계정의 도움이 필요한 경우 웹마스터를 호출해 주세요.** 마스터 전용 권한은 다른 계정에 별도로 양도하거나 부여할 수 없으며, 해당 업무는 웹마스터가 직접 처리합니다.

## 4. 권한 비교

| 기능 | 마스터 관리자 | 일반 관리자 |
|---|---|---|
| 승인된 Google 계정 로그인 | 가능 | 가능 |
| 발송 이력 조회 | 가능 | 가능 |
| 7일 이내 PDF 다운로드 | 가능 | 가능 |
| 관리자 계정 목록 관리 | 가능 | 불가 |
| 일반 관리자 추가 | 가능 | 불가 |
| 관리자 권한 회수 | 가능 | 불가 |

## 5. 이용 시 주의사항

- 관리자 계정 및 인증 정보를 다른 사람과 공유하지 마세요.
- 검진 결과와 개인정보는 승인된 업무 목적으로만 이용하세요.
- 다운로드한 PDF는 안전하게 관리하고, 보관 목적 종료 시 관련 규정에 따라 파기하세요.
- 공용 기기에서는 이용 후 반드시 로그아웃하세요.
- 관리자 권한이 더 이상 필요하지 않다면 웹마스터에게 회수를 요청하세요.

## 6. 자주 묻는 질문

**Q. 로그인했는데 접근이 거부됩니다.**  
A. 웹마스터에게 계정 승인 상태를 확인해 주세요.

**Q. 관리자 계정 메뉴가 보이지 않습니다.**  
A. 일반 관리자에게는 해당 메뉴가 표시되지 않습니다.

**Q. PDF를 다운로드할 수 없습니다.**  
A. 생성 후 7일이 경과했는지 확인해 주세요.

**Q. 관리자 추가 시 Google 인증을 다시 요청합니다.**  
A. 계정 관리 작업에는 추가 본인 인증이 필요할 수 있습니다.

**Q. 별도의 관리자 비밀번호를 설정해야 하나요?**  
A. 아니요. Google 계정으로 로그인합니다.

**Q. 마스터 관리자 기능이 필요합니다.**  
A. 웹마스터를 호출해 주세요. 마스터 전용 권한은 양도되지 않으며 웹마스터가 직접 처리합니다.

## 7. 운영 안내

현재 v1.2.0 운영 시스템은 **이메일 전송 일시 중지 상태**입니다. 따라서 새 이메일 발송 기록이 생성되지 않을 수 있습니다.
