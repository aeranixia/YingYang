# 운영 개인정보 처리경로 확정 요청서 — 한 번의 비공개 검토용

2026-11-01. 사용자에게 이미 확인받은 상호·책임자 직책·부서·번호·차트 수동 처리 여부는 다시 묻지 않는다. 공개 자료와 API로 채울 수 없는 실제 계약/계정 사실 및 법적 판단만 남긴다. 환자 화면이나 공개 이슈에 이 요청서를 작성해 게시하지 않는다.

## 운영자가 해야 할 단 하나의 행동

**이 요청서와 연결된 근거/운영 기준을 기존 계정 소유자와 한의원 대표원장에게 전달하여, 필요한 제공자·개인정보 법률 검토를 거친 ‘처리경로 확정 회신 1건’을 비공개로 받아 주세요.** 계약서 원문·결제 주소·개인 이메일·실명·토큰을 채팅/GitHub에 붙일 필요는 없다. 계정 소유자가 실제 적용 문서를 열람하여 아래 사실과 근거 식별자/검토 결론만 내부 회신에 남기면 된다. 확인되지 않은 표에 서명만 받는 절차가 아니다.

## 정확히 없는 자료와 채울 수 없는 문구

| 없는 사실/증빙 | 왜 공개 자료/API만으로 확정 불가한가 | 이 증빙으로 최종 채울 항목 |
| --- | --- | --- |
| 실제 Firebase/GCP 청구·이용 계약의 고객/계약법인, 별도 계약 유무, 한의원이 계정 소유자에게 부여한 처리 범위 | 약관은 서비스별로 다르고 계약법인은 청구 주소·별도 합의에 따라 달라짐. CLI 로그인/프로젝트 소유 권한은 한의원과의 계약 증거 아님 | 위탁업무·수탁자 법적 명칭/연락처와 해당 계약/재위탁 관리 범위 |
| 사용하는 Hosting/Auth/App Check(reCAPTCHA)/Logging·일반 Gmail 경로에 적용되는 국외 처리 명세 또는 제공자 확인 회신 | Auth 미국·서울 처리 서버는 확인했으나 global을 국가로 바꿀 수 없음. 전체 Google 시설/수탁자 목록은 이 계정의 모든 처리국가 확정 자료가 아님. 일반 Gmail에 Cloud/Workspace 계약을 대입할 수 없음 | 경로별 이전받는 자·국가·항목·시기/방법·목적·기간·연락처·거부 효과 및 실제 법적 근거 |
| PDF 원본의 법적 기록 분류 및 현재 서명 증명/수동 관리 기준에 대한 적합성 검토 결론 | 법정 종류별5/10년은 확인되지만 PDF라는 파일 형식만으로 분류할 수 없음. 브라우저 서명7일은 장기 법적 증빙 보관을 자동 충족하지 않음 | 법정 보존 대상의 정확한 범위/기간·근거, 목적 달성 사본 파기 기준 및 필요한 동의 증빙 처리 |

취소/미내원·CRM·관리자·문자·차트 자동화 기능 검토를 요청하지 않는다. 개인정보처리방침 고지 의무를 완성하는 데 필요한 자료만 다룬다.

## 계정 소유자/검토자가 사용할 준비된 요청 문안

“현재 YingYang은 Firebase Hosting·Authentication·App Check/reCAPTCHA Enterprise, 서울 Functions·비공개 GCS, global Logging, 일반 Gmail API 발신과 한의원 네이버 메일 수신을 사용합니다. 첨부한 처리목록을 기준으로 이 계정에 실제 적용되는 계약법인·고객/처리자 관계 및 국외 처리 국가/수탁자·보관/삭제 명세를 확인해 주십시오. 일반 Gmail을 Workspace로 가정하지 말아 주십시오. 한국 개인정보 보호법 제26조·제28조의8·제30조·시행령 제31조에 맞는 필수 고지와 법적 근거, 의료법 기록 분류 및 현재 동의 증빙 방식의 적합성을 확인하여 최종 게시에 사용할 사실·근거와 수정해야 할 문구를 하나의 회신으로 정리해 주십시오. 실제 환자 자료나 인증 비밀은 제공하지 않습니다.”

## 회신의 완료 조건

- 위탁 계약 상대와 고객 관계를 실제 적용 문서로 확인했다는 근거가 있어야 한다.
- 실제 경로에 해당하는 국외 처리 고지의 필수 열과 법적 근거가 비어 있지 않아야 한다. 전체 가능 국가를 임의 나열하거나 ‘국외 이전 없음’으로 대체하지 않는다.
- PDF 기록 분류/사본 파기·동의 증빙 결론이 있어야 한다. 새 저장소가 필요하다는 결론이면 만들기 전에 비용/범위 승인을 별도 요청한다.
- 이 회신은 운영 main 병합·배포 승인을 대신하지 않는다. 확인 후 최종 문안 반영·승인 및 환경별 발송 경로 점검이 필요하다.
