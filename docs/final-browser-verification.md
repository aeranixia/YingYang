이슈 #4 댓글6544795734 기준. 이전 Chrome A안 관찰 계획보다 최신 지시를 우선한다.

## 조사 중단과 검증 한계

Chrome 자동화 App Check403은 원인 미확정으로 기록하고 추가 재현·조사·집계 조회를 중단했다. 보안 설정은 변경하지 않았다.

이번 환경에는 일반 사용자 브라우저를 조작하는 연결 도구나 실제 모바일 기기가 없다. 설치 파일 메타데이터만 읽어 Windows Chrome156.0.8078.79, Edge156.0.4314.50을 확인했으며 실행하지 않았다. 설치 확인은 기능 검증이 아니다. 자동화를 일반 사용자 환경으로 대체하거나 새 재현을 수행하지 않았다.

## 사용자 또는 코디의 수동 검수 항목

Staging만 사용하고 가상 정보만 입력한다. 실제 메일 발송이나 발송 창 개방은 금지한다.

1. 일반 Chrome·Edge·가능한 실제 모바일에서 브라우저/OS 버전과 화면 방향을 기록한다.
2. 기존 테스트 계정 로그인, 소/중/대, 후천적10문항·타고난40문항의 이전 이동/수정·저장/새로고침 이어하기를 확인한다.
3. 두 검사 완료 후 가상 정보·동의 화면 전환과 동의 누락 차단을 확인한다.
4. 현재 제공되는 모의 전송 경로임이 명확한 경우에만 모의 처리 결과를 확인한다. 실제 발송 경로와 구분할 수 없으면 전송 버튼을 누르지 않는다.
5. 모의 성공 화면만으로 PDF 한글/표/시간/파일명까지 육안 검증했다고 기록하지 않는다. 기존 승인된 가상 PDF와 이번 생성 결과를 구분한다. 독립적인 PDF 조회 경로가 없다면 해당 부분은 미검증으로 남긴다.
6. 오류가 생기면 환경·발생 단계·비식별 오류 코드만 전달하고 반복 시도하지 않는다. 비밀번호·토큰·환자 정보·원본 네트워크 본문을 공개하지 않는다.

## 운영 전제 후속 결정

진료차트 수동 등록은 한의원 직원이 자체 처리한다는 운영 결정을 반영한다. 자동 차트/CRM 연동 승인이 아니며 실제 등록 절차를 검증한 것은 아니다. 이전 문서의 ‘차트 등록인가 메일함 조회만인가’ 질문은 최신 결정으로 대체한다.

예약 취소·미내원 처리 추가 논의는 현재 생략한다. 이는 보관·삭제 정책 확정이나 법적 의무 면제 판단이 아니다. 정식 상호/법적 주체·보호책임자·권한/계약·동의 증빙·국외 처리·기록 분류/보존기간 등 미확인 사항은 유지한다. 새로운 법적 결론은 내리지 않았다.

## 변경 범위

문서만 갱신했다. 코드 수정, Staging/운영 배포, 실제 이메일·발송 창 개방, 신규 자원, main 병합·태그 생성 없음. 문서 형식/링크를 점검하며 npm 테스트·빌드는 재실행하지 않는다. 일반 사용자 최종 검증은 미완료이며 이슈 #4는 열린 상태로 유지한다.
