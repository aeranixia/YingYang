# YingYang 관리자 시스템 이용 안내 (카카오톡 공유용)

📢 **YingYang 관리자 시스템 이용 안내**
버전: v1.2.0

🔗 관리자 페이지
https://yingyangcheck.web.app/admin

━━━━━━━━━━━━━━
🔐 **1. 로그인**
① 관리자 페이지 접속
② [Google로 로그인] 선택
③ 승인된 Google 계정 선택

※ 사전 승인된 계정만 이용할 수 있습니다.

━━━━━━━━━━━━━━
👤 **2. 일반 관리자**
✅ 발송 이력 조회
✅ 날짜 및 처리 상태별 조회
✅ 검진 결과 PDF 다운로드 (생성 후 7일 이내)

📄 PDF 다운로드 방법
① [발송 이력]에서 기록 찾기
② 다운로드 가능 여부 확인
③ [다운로드] 선택

※ 일반 관리자는 관리자 계정 목록·추가·권한 회수 기능을 이용할 수 없습니다.

━━━━━━━━━━━━━━
👑 **3. 마스터 관리자**
일반 관리자 기능에 더해 관리자 계정 관리가 가능합니다.

관리자 추가:
① [관리자 계정] 선택
② 추가할 Gmail 주소 입력
③ [관리자 추가] 선택
④ 필요 시 Google 본인 인증

권한 회수:
① [관리자 계정]에서 대상 확인
② [권한 회수] 선택
③ 필요 시 Google 본인 인증

📌 **마스터 관리자 계정의 도움이 필요한 경우 웹마스터를 호출해 주세요.**
마스터 전용 권한은 다른 계정에 별도로 양도하거나 부여할 수 없으며, 해당 업무는 웹마스터가 직접 처리합니다.

━━━━━━━━━━━━━━
⚠️ **4. 이용 시 주의사항**
• 관리자 계정 공유 금지
• 개인정보·검진 결과는 승인된 업무 목적으로만 이용
• 다운로드한 PDF는 안전하게 관리하고 관련 규정에 따라 파기
• 공용 기기 사용 후 로그아웃

━━━━━━━━━━━━━━
❓ **5. 자주 묻는 질문**
Q. 로그인 후 접근할 수 없어요.
A. 웹마스터에게 계정 승인 여부를 확인해 주세요.

Q. [관리자 계정] 메뉴가 없어요.
A. 일반 관리자에게는 표시되지 않습니다.

Q. PDF 다운로드가 안 돼요.
A. 생성 후 7일이 지났는지 확인해 주세요.

Q. 별도 비밀번호가 필요한가요?
A. 아니요. Google 계정으로 로그인합니다.

Q. 마스터 관리자 기능이 필요해요.
A. 웹마스터를 호출해 주세요. 전용 권한은 양도되지 않습니다.
