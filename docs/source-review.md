# 문항 원본 대조

사용자가 제공한 후천적·타고난 검사지 사진 두 장을 기준으로 `src/questions.ts`에 50문항을 옮겼습니다. 굵은 글씨는 `Segment.bold`로 분리하며 `<strong>`으로 표시합니다. 개인정보 기입란은 요청 범위에 없으므로 구현하지 않았습니다.

타고난 검사지의 노란 입력 칸을 1~40번까지 확인한 결과 요청 문서의 분류표와 일치합니다. 가 11개 / 나 10개 / 다 10개 / 라 9개이며 중복과 누락이 없습니다.

원본 표현을 임의 교정하지 않고 유지한 확인 사항:

- 후천적 8번 ①: 사진은 “재치가 유머가”로 읽힙니다. 문법적으로 어색하지만 그대로 옮겼습니다.
- 후천적 9번 ②: 단점을 묻지만 긍정적인 설명과 후회를 함께 적은 원문을 유지했습니다.
- 후천적 10번 ③: “음정도 애절하고”로 읽히는 부분을 그대로 옮겼습니다.
- 타고난 25번: “축 가라 앉는다” 띄어쓰기를 유지했습니다.
- 타고난 29번: “안타고”, 40번: “일년” 표기를 유지했습니다.

사진의 기울기와 인쇄 상태 때문에 굵기 경계가 인접 글자에서 모호할 수 있습니다. 읽을 수 있는 강조 구절을 반영했으며, 위 후천적 표현과 정확한 굵기 경계는 원본 고해상도 스캔 또는 작성자 검토가 있으면 최종 확정할 수 있습니다. 검사 내용의 타당성이나 체질 판정 공식은 제공되지 않았으므로 검증하거나 추정하지 않았습니다.
