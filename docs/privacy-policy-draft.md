현재 사전 동의 증명의7일은 유효성 기간입니다. `expire()`는 만료된 응답/완료 증명을 제거하지만 사전 동의 localStorage 키 자체는 즉시 제거하지 않습니다. 해당 키는 전체 삭제 때 제거하거나 재동의 때 교체합니다. 만료된 동의 키의 물리 정리·최종 보유기간은 [확인 필요]이며, 추가 기능 변경이 필요하면 별도 승인받습니다.

### 제3자 제공·처리위탁

한의원이 운영하는 앱에서 해당 한의원으로 접수하는 것을 기본 시나리오로 문서화합니다. 개발자·운영 지원자·클라우드/메일 사업자의 실제 접근·계약은 별도 확인합니다. 이메일 주소 확보나 한의원 운영 방향만으로 모든 외부 처리가 내부 업무라고 확정하지 않습니다.
