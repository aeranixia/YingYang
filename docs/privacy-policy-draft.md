### 권리·거부·문의

이용자는 동의를 거부하거나 개인정보 열람·정정·삭제·처리정지·동의 철회를 [개인정보 보호책임자/부서·전화·이메일·신청 절차: 확인 필요]에 요청할 수 있습니다. 본인 확인에 필요한 최소 정보와 처리 기한/제한 사유는 [확인 필요]입니다. 민감정보가 포함된 PDF 원본을 공개 이슈에 제출하도록 요구하지 않습니다.

거부 시 제한은 필요한 목적별 검사 저장/완료 확인/이 경로의 PDF 전송에 한정해 설명합니다. 다른 진료·상담 전체가 제한된다고 안내하지 않으며 대체 문의 방법은 [확인 필요]입니다. 이미 보낸 메일의 회수/타인의 다운로드 원격 삭제는 보장하지 않습니다. 진료기록·법정 보존의 삭제 제한은 사유와 기간을 확인해 안내합니다.

14세 미만 이용 허용 여부·법정대리인 절차, 적용되는 이용자 범위는 [확인 필요]입니다. 현재 테스트 계정 제한을 실제 서비스의 연령 정책으로 간주하지 않습니다.

### 자동 저장·보안·변경 안내

브라우저 localStorage로 응답·진행·동의/완료 증명·보관 메타데이터·글자 크기를 관리합니다. 글자 크기는 검사 삭제 시 유지할 수 있고 무작위 회차 표식은 오래된 응답 복구 차단용으로 남습니다. 공유기기는 검사 종료 후 직접 삭제를 권고합니다. 브라우저 저장 거부 시 이어하기 등이 제한될 수 있습니다. Auth/reCAPTCHA 등의 장치·거부 방법과 영향은 [제품별 확인 필요]입니다.

접근 제한·Auth/App Check·서버 검증·관리 비밀 분리·본문 로그 금지·고정 수신자·공유 중복 방지·KST 일일50회 시도 상한을 적용하는 방향입니다. 이것이 유출/중복/전달을 완전히 보장하는 것은 아닙니다. 현재 PDF 비밀번호 암호화/종단간 메일 암호화를 구현·검증했다고 표시하지 않습니다. 운영 안전조치·담당자·사고 신고/권리 구제 창구는 [확인 필요]입니다.

방침 확정 버전·시행일·변경 공지 위치/시기·이전 버전 보관은 [확인 필요]입니다. 이 검토 문서의 작성일은 운영 방침 시행일이 아닙니다.

### 일반 개인정보 수집·이용 (독립 체크)

### 건강 관련 민감정보 처리 (별도 체크)
